# 树莓派与 FPGA 联调技能包

本目录将双板接口、产线隔离和部署中可复用的方法整理成操作流程，可用于 Linux 上位机调用 FPGA HTTP 推理服务的项目。测试入口和结果见 [sim/](../sim/readme.md) 与[验证记录](../report/software_validation.md)。

| 方法 | 适用场景 | 使用方法 | 失效条件 | 来源与验证 |
| --- | --- | --- | --- | --- |
| 双板接口分层检查 | 上位机收到错误、超时或坐标不一致 | 按 [interface_checks.md](interface_checks.md) 分别检查服务、文件字段、返回结构与看板写入 | 服务协议、预处理或类别表改变后，需更新用例 | 项目将 Zynq `/predict` 与本地看板 `/api/device/ingest` 分开；图像格式与标签测试验证请求和结果处理 |
| 单相机多产线隔离 | 一个采集源对应多个逻辑产线 | 选择活动产线；每条产线独立数据库与图片路径；测试非法编号及跨产线写入 | 多相机并发或多进程共享迁移需额外设计 | 从单产线迁移到五产线后的隔离需求提炼；对应 `test_production_lines.py` |
| 可迁移源码导出 | 换机或生成独立工程包 | 用 `tools/export_raspberry_pi.py` 导出到新目录，检查许可/文档/入口，再单独迁移标定和数据库 | SDK、模型、系统包或已标定参数缺失时仍需补充 | 原导出入口引用缺失配置文件；本次整理补齐文件并验证导出包的命名、许可与运行入口 |

以上验证覆盖软件接口和本机文件操作。跨板型部署及整机机械动作验证记录待补充。方法来自工程现有接口和测试中的具体约束；大模型协作整理过程见[协作记录](../report/ai_collaboration.md)。
