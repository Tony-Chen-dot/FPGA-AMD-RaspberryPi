# 语音与看板 AI 助手

`voice/service.py` 是看板文字问答与语音问答共用服务。输入问题后，从检测数据库检索上下文，再通过原有模型客户端生成回答，保存对话，并按调用方式合成语音。

- `speech/`：唤醒、语音识别、语音合成。
- `context/`：检测数据上下文。
- `dialogue/`：提示词、大模型客户端、历史记录。
- `config.py`：环境配置；`status.py`：运行状态；`main.py`：后台语音循环。

现场设置仍在 `config.sh`，原模型、提示词、音频设备、语速等值保持不变。`VOICE_WAKE_ENABLED=0` 时不启动后台唤醒进程，看板中的 AI 问答仍可使用。

加载好配置后可以执行：

```bash
bash scripts/start/voice.sh
```

通常直接使用根目录 `start_all.sh`，由它按照配置决定是否启动后台唤醒。Vosk 模型和语音模型仍使用原来的外部目录，不包含在源码重排中。

## 产线范围

系统背景为树莓派管理产线 1～5、Zynq 提供推理加速。看板问答读取当前所选产线的独立数据库和会话；后台语音读取 `PRODUCTION_LINE_ID` 指定的采集产线。数据上下文包含产线编号，提示词要求仅依据当前产线数据回答，不能把单产线统计当成全厂汇总，也不能编造无信号产线的实时状态。
